# AIbook 快速开始验证

## 验证目标

确认 AIbook（人工智能学习资料库）的快速开始流程能够完成环境准备、首个接口调用，并能明确后续学习入口。

## 验证步骤

### 1. 确认前置条件

- 已准备可用的模型服务 API（应用程序接口）访问密钥。
- 已安装 Python（编程语言）和项目依赖。
- `experiments/.env` 中存在 `API_KEY`（接口访问密钥）。

### 2. 运行首个示例

在项目根目录执行：

```bash
python experiments/main.py
```

### 3. 检查结果

- 请求正常完成，并在终端输出模型回复。
- 如果失败，先检查 API 密钥、`base_url`（模型服务地址）、`model`（模型标识）和网络连接。
